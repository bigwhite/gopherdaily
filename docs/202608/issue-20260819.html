Harness 不是一次性脚手架：自进化 Coding Agent 系统如何越跑越强
我们在专栏里手搓的 Agent Harness 本质上都是写死的工程约定，而南京大学团队最新发布的综述《Self-Evolving Coding Agents》则指向了下一个前沿：如何让 Harness 在运行中自我进化？本文系统拆解了该综述提出的五维自进化分类法（框架、记忆、技能/工具、模型、工 作流拓扑），厘清了任务内、任务后与阶段性进化的时机与证据链，并结合实战专栏中的 Context Compaction、错误自愈、Subagent 等模块进行深 度串讲，为开发者绘制了一张从“手工静态 Harness”迈向“越跑越强的自生长智能体”的完整工程地图。
