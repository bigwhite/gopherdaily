Go技术生态

Go 也要实现零堆分配？noalloc：让每一次内存分配都无处遁形
noalloc 试图把 Go 的零堆分配从一种依赖经验的优化技巧，变成一种能够持续验证的工程约束。它通过静态分析函数调用链识别堆分配，并提供固定容量的数据结构和 Region 内存复用机制。它并不能消除 Go GC，也不是实时性保证，但为 Go 在高性能、低延迟和资源受限场景 中的优化提供了值得关注的新方向。

继Anthropic之后，OpenAI 也重建了自己的版本控制系统
OpenAI 最新披露了内部 Git 后端系统 Pando 的设计。面对 Codex 带来的高并发开发负载，OpenAI 没有抛弃 Git，而是通过因果>一致性、Packfile 复用、区域缓存和后台 Compaction，重新设计 Git 服务端架构。Pando 将 Push 中位延迟降低近 5 倍，每天处理近 PB 级 Git 数据。从 10 周完成系统建设，到 Codex Agent 参与实现，再到 Lean 和 TLA+ 参与形式化验证，这个项目不仅展示了分布式存储架构的创新，也 揭示了 AI Agent 正在如何改变软件工程基础设施
